# Frontend Next.js

## Rodando local

1. Copie `.env.example` para `.env.local`
2. Instale dependencias:

```bash
npm install
```

3. Inicie o app:

```bash
npm run dev
```

App: http://localhost:3000

## Telas disponiveis

- `/` restaurantes
- `/register` cadastro
- `/login` login
- `/cart` carrinho e enderecos
- `/orders` historico
- `/owner` painel do restaurante
- `/courier` painel do entregador
